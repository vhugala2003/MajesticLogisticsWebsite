# Majestic by Vhugala Nthemeni

Static trucking and logistics website.

## View the website

After GitHub Pages finishes its first deployment, the site will be available at:

https://vhugala2003.github.io/MajesticLogisticsWebsite/

## Run locally

From this folder, run:

```powershell
python -m http.server 8001
```

Then open http://localhost:8001.

The quote form prepares a WhatsApp message for 069 498 9914. The uploaded truck image is stored in `majestic-truck.png`; Three.js is loaded from jsDelivr for the 3D image effect, with a local image fallback.
